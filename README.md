# goit-markup-hw-01

GoIT Fullstack HTML/CSS homework #1: **semantic HTML markup**.

The project is the landing page of **WebStudio**, a fictional web studio ("Effective Solutions for Your Business"), built from the course mockup. Each homework in the `goit-markup-hw-0X` series builds on the previous one.

**Live page:** [https://vladyslav-humenskyi.github.io/goit-markup-hw-01/](https://vladyslav-humenskyi.github.io/goit-markup-hw-01/)

## What's done

- Semantic page structure with `header`, `nav`, `main`, `section` and `footer`
- Sections: header with logo and navigation, hero, features, team and footer with contacts
- Team member photos and logo in `images/`
- Markup only; no CSS yet

## Structure

```
index.html
images/   logo and team photos
```

## Run locally

No build step. Open `index.html` in a browser or serve the folder with a static server such as VS Code Live Server.
